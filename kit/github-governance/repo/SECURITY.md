# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| current | Yes |
| older releases | Maintainer discretion |

## Reporting a Vulnerability

Please report vulnerabilities privately through GitHub private vulnerability
reporting at `https://github.com/OWNER/REPO/security/advisories/new` or by
emailing SECURITY_CONTACT_EMAIL.

Do not open public issues for vulnerabilities, exploit details, leaked tokens,
or credential material.

Maintainers aim to acknowledge security reports within 24 hours. The default
coordinated disclosure window is 90 days unless reporter and maintainer agree on
a different timeline.
